# BYR Docs Drafting 尺寸标注图

尺寸标注图是指对室内环境（如寝室）的若干物体进行测量后，在相应实拍图中对物体的大小进行标记，从而得到的图片。

## 基本规范

1. 图片使用 Typst 进行数据标注，需插入实拍图并按[制图规范](#制图规范)进行处理。相关用法请见[作图教程](#作图教程)。
2. 图片可以采用横版或竖版，但画幅的短边必须设定为 4032。

## 实拍图规范

原则上，拍摄者需正对物体，这样可以确保绝大部分尺寸标注线与拍摄视角保持**水平**（左右）、**竖直**（上下）、**纵深**（前后）三个方向，以便使用不同颜色的线条加以区分。

另外，建议优先使用 4:3 或 3:4 的比例进行拍摄。即便要裁剪，也建议保持 4:3 或 3:4 的比例进行裁剪。

## 制图规范

如无特殊情况，请务必遵守以下制图规范，以确保图片清晰、表意精确、观感一致。

1. 严丝合缝。对于形状规则的物体，尺寸线须尽可能贴合物体的边界线；线的末端须尽可能贴合物体的拐角，或物体之间的交界点。不可直接绘制横跨物体表面的尺寸线。
2. 虚实分明。在标注尺寸时，都应使用有箭头的实线。但对于形状不规则的物体，可能需要绘制无箭头的辅助线，以便顺利标注尺寸。
3. 遵循透视。实拍图均为三维效果图，因此在绘制辅助线时，必须按照透视原则来决定线的位置。
4. 方向有别。不同方向上的线需使用不同的颜色。
    - 水平方向的线使用红色
    - 竖直方向的线使用绿色
    - 纵深方向的线使用蓝色
    但在遇到线的颜色和物体颜色高度相似的特殊情况时，建议使用黑色线代替。

## 作图教程

### 文件结构

请在本目录内建立新目录，**每个目录代表一张标注图**。请将实拍图命名为 `bg.jpg` 或 `bg.png`，一并放入目录内。再在相应目录内建立 `main.typ`，这是标注图的描述文件。

例如，你可以建立一个 `某图片` 目录。这样一来，从当前目录看，整个目录的结构就是

```
.
├── lib.typ
├── README.md
├── 某图片
│   ├── bg.jpg
│   └── main.typ
└── ...
```

`lib.typ` 包含了绘图过程中用到的组件和样式。它已经写好，你无需关注内部细节。

### 基本格式

而在 `某图片/main.typ` 中，你需要按如下结构编写描述。

```typ
// 调用库文件
#import "../lib.typ":*
// 声明实拍图（注意：图片路径是相对于本 README.md 而言的）
// dx, dy 表示将图片水平/竖直位移的量（默认 0, 0）
// scale 表示将图片缩放的比例（默认 100%）
// rot 表示将图片旋转的度数（默认 0deg)
// width, height 表示定义画幅的大小（默认5736, 4032)
#show:preset.with("某图片/bg.jpg",dx:112,dy:-79,scale:114%,rot:0.55deg)
//画布
#context canvas({
    //...描述内容
})
```

`anno-line` 是最常用的标注要素，它定义了从 `a` 到 `b` 两点间的有箭头线段，并将 `[]` 中的内容呈现出来。

```typc
// (10,10), (100,100) 是箭头首尾两点的坐标
// red 是箭头和文字的颜色，此处可以使用的有 red, green, blue, black
// rel 定义了文字在线条上位置。70% 表示位于首尾两点间离首点 70% 距离处的位置（默认 50%）
// shift 定义了文字和线条的相对方向。为 false 时，文字位于以首点为圆心，线条的顺时针方向；为 true 时，文字将置于逆时针方向（默认 false）
// pad 定义了文字到线条的距离，你可以增加 pad 来将文字放在更远处（默认 1.5）
anno-line((10,10),(100,100),red,rel:70%,pad:1.5,shift:true)[20]
```

`dash-line` 是辅助线，用于辅助**读者**看图，它定义了从 `a` 到 `b` 两点间的虚线段。

```typc
// (20,20), (200,200) 是辅助线首尾两点的坐标
// blue 是虚线的颜色
dash-line((20,20),(200,200),blue)
```

`helping-line` 是绘图辅助线，用于辅助**作图者**看图和制图，它定义了从 `a` 到 `b` 两点间的细线段。

```typc
// (30,30), (300,300) 是绘图辅助线首尾两点的坐标
// fill 定义了绘图辅助线的颜色（默认 gray）
helping-line((30,30),(300,300),fill:black)
```

### 编译

编译需在[与本 README.md 同级目录](./)下进行，例如：

```bash
typst compile 某图片/main.typ --root . -f png --ppi 36
```

编译通过后将生成 `某图片/main.png`，你可打开查看。

在编写过程中你也可以通过 `typst watch` 命令实时编译图片，这样能更方便地确认图片上坐标的位置。

```bash
typst watch 某图片/main.typ --root . -f png --ppi 36
```

### 辅助功能

以下辅助功能是通过 `compile`/`watch` 时增加命令行参数来打开的。通过在图片上呈现这些辅助要素，可以帮助你更顺利地作图。

注意：**不要在正式发布的图片中打开下述辅助功能。**

#### 网格线

通过 `RULER=1` 启用。

```bash
typst watch 某图片/main.typ --root . -f png --ppi 36 --input RULER=1
```

从 (0,0) 起，水平/竖直每 200 单位存在一条浅网格线，每 1000 单位存在一条深网格线。通过网格线可以快速确定一个位置的大致坐标。

#### 绘图辅助线

通过 `HELPING_LINE=1` 启用。

```bash
typst watch 某图片/main.typ --root . -f png --ppi 36 --input HELPING_LINE=1
```
